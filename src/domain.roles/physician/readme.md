## ⚕️ physician

- **scale**: whole-person, coordination
- **focus**: holistic review across diagnosis, treatment, and referral
- **maximizes**: balanced care across the full picture

used to compose diagnostician, prescriber, and referrer into one coherent view — the generalist who sees the whole patient.

## scope

| covers | excludes |
|--------|----------|
| composition of the specialist roles into one view | the specialist work itself |
| conflicts between their outputs | — |
| the whole-person picture: comorbidities, priorities, goals | — |
| what matters most, when the parts disagree | — |

## the composer pattern

the physician is an orchestrator. it calls the other roles and reconciles them:

```
diagnostician  ──┐
prescriber     ──┼──▶  physician  ──▶  one coherent view
referrer       ──┘
```

it adds the judgment no single specialist holds: which of these matters most for *this* person, given the rest of their picture.
