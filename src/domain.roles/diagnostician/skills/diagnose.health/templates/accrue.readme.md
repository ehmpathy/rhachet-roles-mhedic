# accrue/ — reusable cited facts

this dir holds the **generic, case-neutral, cited facts** each research stone lifts out of its case
yield, per `rule.require.accrue-research`.

## .the split

- the **case yield** keeps the applied, patient-specific interpretation (obscure tier)
- **`accrue/inventory.of=<topic>.md`** keeps the shareable fact (fullsun tier), stated with no
  patient in it

## .what each entry carries

1. the generic fact, case-neutral ("feline VAAE incidence ~52/10,000")
2. the citation — bhrowser source + verbatim quote + URL/PMID
3. the retrieval date
4. the topic scope (what class of case it serves)

## .promote

when the route completes, promote proven-generic entries into the repo-shared
`.agent/repo=.this/role=any/briefs/inventory/` (per `rule.require.source-inventory`). `accrue/` is the
cheap per-route hold; the shared inventory is the curated cross-case home.
