# p10.drug-induced

> ⚠️ **not veterinary advice — informational only.** consult a licensed veterinarian; if this looks
> like an emergency, call an emergency vet now.

## .cause

**drug-induced** — medications that slow gut motility or promote dehydration can precipitate
constipation. this is the cause the three correlation briefs attribute against for an *exposure*.

## .expectation

- **probability:** **p10** (uncommon as a sole cause; depends on the specific drug; ordinal bucket)
- **causal-chain:** `drug (opioid / diuretic / anticholinergic / etc.) → slowed motility and/or fluid loss → slow transit → dry hard stool`

## .anchor

From [Merck Veterinary Manual](https://www.merckvetmanual.com/digestive-system/diseases-of-the-large-intestine-in-small-animals/constipation-obstipation-and-megacolon-in-small-animals):
> "Some drugs (eg, opioids, diuretics, antihistamines, anticholinergic agents, sucralfate, aluminum hydroxide, potassium bromide, and calcium channel blocking agents) promote constipation via differing mechanisms."

From [Cornell Feline Health Center — Constipation](https://www.vet.cornell.edu/departments-centers-and-institutes/cornell-feline-health-center/health-information/feline-health-topics/constipation):
> "the side effects of various drugs can predispose to constipation in cats."

## .the mechanisms differ by drug class

| class | how it constipates |
|-------|--------------------|
| **opioids** (e.g. buprenorphine — common post-op in cats) | directly slow colonic motility |
| **diuretics** (e.g. furosemide) | fluid loss → dehydration → dry stool |
| **anticholinergics / antihistamines** | reduce gut smooth-muscle activity |
| **NSAIDs** (indirect) | *not* on Merck's direct list — act via appetite loss / dehydration; see the robenacoxib-onsior correlation brief |

## .note

**history is the key** — a good med history "rule[s] out iatrogenic causes" (Merck). the vet-visit
exposures (opioid for the blood-draw sedation, an NSAID like Onsior) route through here.
