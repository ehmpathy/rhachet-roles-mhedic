## .the no-regret core (start now, keyed to the acuity floor)

### 1. the clinician clearance — the floor-lift, first (acuity: EMERGENCY)

because the floor is emergency-until-cleared, the first no-regret action is a **clinician perfusion +
neuro check** — the same check that lifts the floor. it is non-invasive, harm-none under every
branch, and it is what converts an emergency-until-cleared case into a step-down.

- **perfusion check** (limb warmth, pulses, pad color) → clears/keeps B16 ATE.
- **neuro check** (proprioception, reflexes) → clears/keeps B13 cord + B10 nerve.
- source: the veto anchors + assay plan (`6.1`, `4.3`); the perfusion-first rule
  (`4.3` step 1: "perfusion first … if abnormal or in doubt → act-as-if-ATE now").

### 2. rest / strict activity restriction (acuity: start now)

confine miki, no jumps/stairs, until the structural branches (B12 fracture, B13 cord) are cleared.

- helps every musculoskeletal branch; shuts the ambulation vector for an un-cleared fracture/cord.
- harm-none: rest ≠ delay-of-transport — an ATE red-line still routes to emergency at once.
- source: `6.3` no-regret core; `8.3` no-regret core.

### 3. gentle, low-stress handle (acuity: start now)

minimize restraint stress at home and transport.

- reduces clot-dislodge stress (B16) and spinal load (B13); helps all.
- source: `6.3` no-regret core.

### 4. gabapentin analgesia (acuity: start now — the no-regret pain path)

gabapentin is the pain path that does **not** trip the ATE/renal/cardiac veto (no QT effect, unlike
the NSAID), so it is safe to start before the NSAID-safety exam.

- **dose (label-target caveat — INFERRED, vet to set):** a feline case series used an **average of
  ~6.5 mg/kg PO q12h** with "satisfactory pain management … no obvious side effects."
  > formal, PMID 23253881 (bhrowser, 2026-08-12): "average dose of **6.5 mg/kg q12h** … satisfactory
  > pain management was achieved … no obvious side effects … a valuable adjunct for the management of
  > chronic pain in cats."
- **⚠️ label caveat:** gabapentin is used **off-label** in cats — there is no feline label dose; the
  figure above is a published case-series average, NOT a label dose, and must be set by a vet to
  miki's real weight. it is renally excreted (dose-down in kidney disease) and can sedate.
- **pair with rest (item 2):** analgesia alone could let an un-cleared fracture bear weight; paired
  with rest, the ambulation vector stays shut.
- source: `accrue/inventory.of=feline-analgesia.feline.md`.

### 5. appetite + hydration monitor (acuity: start now)

track daily food + water intake.

- the B18 hepatic-lipidosis early-warn: if appetite drops past a day or two, the case escalates to
  same-day (`7.2`).
- harm-none: passive observation, no interaction with any branch.
- source: `6.3` no-regret core; `accrue/inventory.of=hepatic-lipidosis` (via `6.1`).

## .what the no-regret core does NOT cover (the coverage boundary)

these are **out of the no-regret core** — they wait on the assay (phase 9.2) or are vetoed (9.3):

| care | why NOT no-regret | where it lives |
|------|-------------------|----------------|
| robenacoxib (onsior) continuation | 3 harm-vectors (cardiac/QT, renal, structural-mask); needs exam + baseline labs first | **conditional** — 9.2 |
| clopidogrel | B16-specific (ATE prophylaxis); anticoagulant, only if a cardiac cause is confirmed | **conditional** — 9.2 |
| assisted nutrition | B18-specific; only if anorexia starts | **conditional** — 9.2 |
| radiograph / advanced films | not routine (no-waste cap); only if step-1 localizes to bone or before B13 manipulation | **conditional** — 9.2 |
| wide surgical excision | B5 FISS-specific; only on a 3-2-1 mass that qualifies | **conditional/veto** — 9.2/9.3 |
| any analgesia that would mask a cold/critical limb; manipulation before clearance; same-site re-injection | actively harmful at the worst-case corner | **vetoed** — 9.3 |
