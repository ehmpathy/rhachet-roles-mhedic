# 4.3.scenario.elimination.assay.plan.yield

> the **ordered assay plan** — the ranked tests (4.2) sequenced into a run order, each with a
> **result → elimination map** (what each outcome drops, keeps, or raises), plus the
> **irreducible-if-inconclusive set** (the scenarios that stay live when every test is ambiguous). this is
> the map that collapses the superposition: run test → read result → drop what it rules out → repeat.
>
> ⚠️ **not veterinary/medical advice — informational only.** the patient was not examined. this is a
> suggested plan a licensed veterinarian could run; no test has been run here. if miki worsens or shows
> red-flag signs, seek a licensed veterinarian now.

## .the collapse map — per live scenario, does a clean result ELIMINATE or only LOWER?

> ⚠️ the guide asks which scenarios each outcome **drops**. but a "clean result" is not always an
> elimination — for the organ/systemic branches a single normal panel only **lowers** (early disease can
> precede a lab rise), it does not fully exclude. so each live scenario is mapped to whether its best
> clean result is a **hard drop** (leaves the superposition) or a **soft lower** (stays live at reduced
> weight). only the hard drops truly collapse; the soft lowers persist and join the irreducible set.

| B# | best clean result | eliminate or lower? |
|----|-------------------|---------------------|
| B16 | unambiguous perfusion | **eliminate** (hard) |
| B10 | clean neuro | **eliminate** (hard) |
| B14 | non-painful joints + clean G5 baseline | **eliminate** (hard) |
| B11 | no soft-tissue pain + clean radiograph | **eliminate** (hard) |
| B1 | flat non-painful injection site | **eliminate** (hard) |
| B12 | clean radiograph | **eliminate** (hard) |
| B13 | clean neuro + clean radiograph | **eliminate** (hard, two-tier) |
| B4 | no acute post-vaccine event | **near-eliminate** (soft-strong; recorded) |
| B15 | mg/kg ≤ target AND renal/hepatic normal | **eliminate** if both; **lower** if only renal normal + dose unknown |
| B18 | normal liver panel | **lower** — early lipidosis precedes enzyme rise |
| B9 | normal urinalysis + no free fluid | **lower** — a slow uroabdomen tail is not excluded by one clean exam |
| B17 | unremarkable metabolic screen | **lower** — one normal panel does not exclude a metabolic process |
| B2 | afebrile + normal CBC + no home signs | **lower→eliminate** only if all three agree; one alone = lower |
| B3 | no fever/ulcer, hind-limb-localized | **lower** (soft-weak — never a clean exclusion) |
| B5 | (no assay) | **never** — persistent watch |

**7 hard eliminations** (B16,B10,B14,B11,B1,B12,B13), **1 near-eliminate** (B4), and **7 that only lower
or need agreement** (B15-partial, B18, B9, B17, B2, B3, B5). the soft lowers are exactly why the
irreducible set is larger than the catastrophic core.

## .the irreducible-if-inconclusive set (every test ambiguous → what stays live)

if every test above returns inconclusive/normal, these branches **cannot be dropped** (`inconclusive ≡
live`; `absence-of-evidence ≠ evidence-of-absence`):

| B# | why it stays live under all-inconclusive |
|----|------------------------------------------|
| B5 (FISS) | no assay today — delayed; a permanent watch/veto regardless of any result |
| B3 (FCV) | soft-weak — no test cleanly excludes it; stays live at low weight |
| B16 (ATE) | if perfusion is ever equivocal (not an unambiguous clean read), stays live + empirical action |
| B13 (spinal) | if neuro is equivocal or no radiograph is taken, the manipulation veto stands |
| B15 (NSAID) | if G1/G2 stay unknown, dose is unknown-not-safe → stays live |
| B18 (hepatic lipidosis) | a normal liver panel only **lowers** — early lipidosis precedes the enzyme rise |
| B9 (uroabdomen tail) | one clean urinalysis/exam only **lowers** — a slow tail is not excluded |
| B17 (other systemic/metabolic) | one normal panel only **lowers** — a metabolic process is not excluded by a single screen |
| B2 (systemic VAAE) | **lowers** unless afebrile + normal CBC + no home signs **all** agree; any single normal alone leaves it live |

**the irreducible core = {B5, B3, B16-if-doubt, B13-if-ungated, B15-if-dose-unknown}** (the hard
persistent-veto backbone) **plus the soft-lower set {B18, B9, B17, B2-if-partial}** that a single clean
result down-weights but does not eliminate.

### ⚠️ two interpretations of "every test inconclusive" — name the interpretation

the size of the irreducible set depends on what "inconclusive" covers, so both interpretations are stated:

| interpretation | what is inconclusive | what stays live | who it is for |
|----------------|----------------------|-----------------|---------------|
| **STRICT (true worst case)** | **no** test yields any usable result — hands-on exam, labs, owner questions, dose calc ALL ambiguous/absent | **all 15 live branches** — no branch gets its eliminative result, so `inconclusive ≡ live` holds for every one | the **treatment plan** must be built for this — it cannot assume any assay settles |
| **PRACTICAL** | the hands-on diagnostics (T2/T4/T5) are equivocal, but the cheap gap-closers still answer (G8 results available, owner questions answered, dose calc done) | the reduced set above: {B5, B3, B16-if-doubt, B13-if-ungated, B15-if-dose-unknown, B18, B9, B17, B2-if-partial} — B4/B14/B1/B11 etc. settle on their cheap answers | day-to-day triage, when the free batch did return answers |

**the plan must cover the STRICT set (all 15).** the practical set is the *expected* residue when the
free batch answers; the strict set is the *guaranteed-safe* residue the phase-9 plan is obligated to
handle. to name only the practical set would under-cover the worst case — so both are carried, with the
strict set as the bound one for treatment.

### the strict set, stratified by treatment consequence (how phase 9 must cover each)

> naming the set is not enough — the plan must know **how** to cover each member. the strict irreducible
> set stratifies by the treatment consequence its severity demands:

| tier | members (from the strict set) | what phase 9 must do |
|------|-------------------------------|----------------------|
| **veto-drivers** (catastrophic) | B16 (ATE), B13 (spinal), B5 (FISS) | carry a **treatment veto** — avoid analgesia that hides a critical limb (B16), no manipulation until cord+bone cleared (B13), no same-site repeat injection (B5). B16's veto fires **empirically/pre-test**. |
| **conditional** (severe) | B15, B18, B9, B17, B2, B10, B12 | **conditional orders** keyed to the assay result — treat if the branch confirms, hold if it clears; each carries its severe-branch care path |
| **no-regret** (moderate/mild) | B14, B11, B1, B3, B4 | covered by the **no-regret core** — supportive care harmless under every branch (analgesia compatible with the vetoes, rest, monitor) |

**the hand-off:** the STRICT set is not a flat list — it is 3 veto-drivers, 7 conditional branches, and 5
no-regret branches. phase 9 inherits exactly this stratification: build the no-regret core first, add
conditional orders keyed to assays, and honor the veto list as the gate. naming the set *and* its
treatment tiers is what makes it actionable, not merely enumerated.
