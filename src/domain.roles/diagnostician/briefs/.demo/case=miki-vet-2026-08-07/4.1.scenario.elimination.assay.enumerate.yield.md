# 4.1.scenario.elimination.assay.enumerate.yield

> the **assay-enumeration matrix**: for every scenario carried out of phase 3 — all 20, not only the 15
> that cleared the floor — the test / exam sign / observation that would **rule it out** (or confirm it),
> graded by **rule-out strength**. the assay phase exists to **shrink the superposition**, so this maps
> each scenario → the observation that collapses it, and flags every branch that **no test can eliminate
> today** as an open hazard that stays live regardless (`absence-of-evidence ≠ evidence-of-absence`).
>
> ⚠️ **not veterinary/medical advice — informational only.** the patient was not examined. these are the
> tests a licensed veterinarian could run; none has been run here. if miki worsens or shows red-flag
> signs, seek a licensed veterinarian now.

## .the inputs

- `3.3.scenario.disentangle.correlation.blend.yield.md` — the 15-scenario live set + the 5 below-floor
- `1.3.intake.gaps.yield.md` — the knowledge gaps (T1–T5 test-needed, G1–G9 cheap-to-close)

## .the strength grades (so no soft/absent rule-out masquerades as eliminative)

> a rule-out is **not binary — it has strength**. this is the spine of the matrix:

| strength | sense | effect of a clean result |
|----------|-------|--------------------------|
| **hard** | an eliminative test exists | a clean result **drops** the branch outright |
| **soft-strong** | a time-bound history/observation | **near-excludes**, but recorded not erased |
| **soft-weak** | exam lowers, cannot exclude | **lowers** weight only; branch stays live |
| **none** | no test today (delayed/undiscoverable) | branch stays live — **open hazard** |
| **implicit** | covered by a kept cousin's test | collapses **with** the cousin's clean exam |
| **closed** | eliminative branch / null control | already out, by construction |

## .the inconclusive rule — an ambiguous result never eliminates

> ⚠️ a rule-out test has **three** outcomes, not two: **clean** (eliminates a hard branch), **confirm**
> (raises it), and **inconclusive** (ambiguous / borderline / not-done). the elimination phase is only
> honest if the **inconclusive** column is explicit — under `superposition-until-elimination`, an
> inconclusive result **keeps the branch live**; it is not a soft "probably fine". this is where most
> real misses happen: a borderline exam read as "clean enough" silently drops a live branch.

| test | clean → | confirm → | **inconclusive / not-done →** |
|------|---------|-----------|-------------------------------|
| T2 perfusion (B16 ATE) | drop B16 | ATE emergency | **B16 stays live** — a partial/ambiguous pulse is NOT a clean perfusion; treat as live until a clear warm-pulse-pink read |
| T2 neuro (B10, B13) | drop nerve/cord | localize the deficit | **B10/B13 stay live** — an equivocal reflex keeps both live |
| T2 ortho (B14, B11, B12) | drop joint/sprain | localize | **stay live** — pain-on-palpation without a clear source keeps B11/B14/B12 all live |
| T1 temp (B2, B17) | drop systemic | fever → systemic | **stay live** — a borderline temp does not clear the systemic branch |
| T5 CBC (B2, B17) | drop inflammatory | inflammation → raise | **stay live** — mild/nonspecific changes are not a clean clear |
| T4 radiograph (B12) | drop fracture | fracture → confirm | **B12 stays live** — a non-diagnostic film (poor positioning) is inconclusive, not clean |
| dose calc (B15) | drop if ≤ target | above label → raise | **B15 stays live** — if mg/dose or weight is unknown (G1/G2 open), dose is **unknown**, not safe |
| liver panel (B18) | drop | enzymes → raise | **B18 stays live** — early lipidosis can precede enzyme rise; short anorexia hx + normal panel only *lowers* |
| urinalysis/abd (B9) | drop | uroabdomen → raise | **B9 stays live** — a normal in-clinic exam does not exclude a slow uroabdomen tail |

**the discipline:** only a **clean** result on a **hard** branch eliminates. inconclusive ≡ live. this is
the operational face of `absence-of-evidence ≠ evidence-of-absence`: a test not run, or run ambiguously,
leaves the branch exactly where it was in the superposition.

## .catastrophic coverage — the veto-lift check

> ⚠️ a **catastrophic** branch's rule-out test does double duty: it also **lifts the treatment veto** that
> branch imposes (phase 9). so for each catastrophic live scenario the test cannot be absent silently — an
> absent test means the veto **can never be lifted at this visit** and must stand. the 3 catastrophic live
> branches (per 3.3 severity: B16, B13, B5):

| B# | catastrophic scenario | rule-out test named? | veto it powers | can the veto lift today? |
|----|-----------------------|----------------------|----------------|--------------------------|
| B16 | feline ATE | ✓ T2 distal-limb perfusion (hard) | avoid analgesia that hides a perfusion-critical limb; emergency-refer | **yes** — a clean warm-pulse-pink exam lifts it |
| B13 | restraint spinal injury | ✓ T2 neuro exam (hard) | avoid manipulation / caution on mobility until cord cleared | **yes** — a clean neuro exam lifts it |
| B5 | injection-site sarcoma (FISS) | ✗ none today (delayed) | avoid repeat injections at the same site; watch the mass | **no — persistent veto**; only 3-2-1 surveillance can lift it later, never at this visit |

**the catch:** B5 is catastrophic **and** has no rule-out test today. under a naive read it would look
"covered" (it has a flag) — but its veto is **un-liftable now**. that is not a gap in coverage; it is a
**persistent veto** that must carry forward into phase 9 precisely because no assay can clear it at this
visit. a catastrophic branch with no test does not get dropped — it converts to a
permanent-until-surveillance constraint.

> ⚠️ **the lift bar for a catastrophic veto is HIGHER than an ordinary rule-out (asymmetric loss).**
> lifting a catastrophic veto wrongly can cost a life, while keeping it wrongly costs only caution — so a
> catastrophic veto lifts only on a **high-confidence clear**, not a single quick check that could miss an
> early/partial process:
> - **B16 (ATE):** the perfusion exam is highly sensitive for a *complete* embolism, but an *early or
>   partial* one can give a borderline read. lift only on an **unambiguous** warm-pulse-pink exam; on any
>   doubt, hold the veto and **serial-recheck** (or Doppler) — do not lift on one equivocal palpation.
> - **B13 (spinal):** a normal neuro exam lifts the *handling* caution, but definitive exclusion of an
>   **unstable bony lesion** before any manipulation-under-sedation needs the radiograph (T4) too — a
>   **two-tier lift** (neuro clears handling; radiograph clears manipulation).
>
> this is the superposition discipline applied to consequence: the graver the branch, the stronger the
> result required to collapse it. an ordinary branch lifts on one clean test; a catastrophic branch lifts
> only on a confirmatory / second-modality clear.

> ⚠️ **a time-critical catastrophic veto is honored EMPIRICALLY, before the test completes.** where a
> catastrophic branch is also **fast-onset** and reversible-only-if-caught-early (B16 ATE), you cannot
> wait for a confirmatory clear while the limb dies — the veto and its action fire **pre-test**:
> - **B16 (ATE):** if the perfusion exam is abnormal *or* even in doubt, act **as-if-ATE now** —
>   emergency-refer, do not delay for imaging; the test confirms in parallel, it does not gate the action.
> - contrast **B5 (FISS):** catastrophic but **slow** — its veto (avoid same-site repeat injection) is
>   honored indefinitely with no time pressure; surveillance runs over months.
>
> so catastrophic coverage has **two axes**: *severity* sets the lift bar (higher = confirmatory), and
> *acuity* (from phase 7) sets **when** the veto fires (fast-onset = pre-test / empirical). a test named
> but slow to complete does not protect a fast-onset catastrophic branch — the empirical action must not
> wait on it.
