outlasts a normal 1–2 day soreness window).

here and folded into `2.2.4`'s magnitude instead.

## .the signal this table hands to 2.2.4

- the **draw-alone** cohort is where the confound breaks: 3 cases, and **none** shows a persistent
  2+day effect — B1 resolves in 1–2 days, B4 is re-attributed to a wrong-site/systemic cause, B2 a
  vet says a draw "should not cause these symptoms." the needle alone reads transient/benign.
- the **vaccine-alone** cohort carries every clear persistent effect (A2, A3, A5) **and** the
  worst-case (A3 steroid). persistent pain concentrates here.
- the **mixed vaccine+draw** cohort (D1, D2) attributes the limp to **the shots**, and D2 — the
  case that mirrors miki's Sunday (persistent limp + reduced defecation + can't jump) — is a
  persistent 2+day effect.
- **restraint alone** (C1, C2, C3) is intermediate: real but mostly transient — C1 "better next
  day," C3 nail-trim "minor irritation, gone in ~72h"; only C2 (NSAID prescribed) reaches 2+ days.
  restraint can cause a limp, but it usually eases in a day or few and rarely needs a drug.

so the ordered relative signal for the **persistent 2+day** effect is:
**vaccine ≳ combined(→shots) > restraint > draw**. `2.2.4` computes the two-direction contingency
from these tallies; magnitude comes from the formal base rate, per the bias-bracket in
`2.2.2 has-bias-recorded`.

## .caveats carried forward

- tiny n; **problem-skew** + **attribution** + **survivorship** bias (per `2.2.2` bias reviews).
  these are **directional** counts, not probabilities.
- social ≠ magnitude: the formal base rate (`2.2.2b`, ~52 VAAEs / 10,000 cats) supplies the *how
  often*; this table supplies only the *which* and the *relative order*.
- social + formal carry **opposite** biases (social over-weights mild, formal over-weights severe),
  so `2.2.4` must **bracket** the truth between them, never pool them.
