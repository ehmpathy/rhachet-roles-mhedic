# 2.2.3.itemize-inventory.stone

## .what

tabulate the gathered experiences into one contingency table — one row per case, tagged by each
exposure + the effect flag. the structured signal the correlations are computed from.

third substone of `2.2.differential.disentangle`.

## .inputs

- `2.2.2.gather-experiences.yield.md` — the raw case list with quotes + urls

## .do

1. **one row per case**, columns:

   | case | url | vaccine | draw | restraint | distress | effect(2+day) | "X alone"? | snippet |
   |------|-----|:-:|:-:|:-:|:-:|:-:|:-:|---|

2. **tag each cell** yes/no/unknown from the verbatim quote — never infer beyond what the text
   says.
3. **mark the "X alone" column** — which single exposure this case isolates (or "mixed").
4. **tally per exposure** — count cases by exposure, by effect, and by "X alone".

## .emit

into `2.2.3.itemize-inventory.yield.md` — the tagged table + the per-exposure tallies.

## .done when

every gathered case is a tagged row, the "X alone" cohorts are marked, and the tallies are
counted.
