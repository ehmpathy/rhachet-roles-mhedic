# 2.1.differential.enumerate.stone

## .what

list the candidate causes — the "suspect lineup". hold every plausible cause of the symptoms
side by side, ranked by clinical logic, each with the observation that tells it apart.

## .why "differential"

short for **differential diagnosis** — from latin *differentia*, "a difference / a feature that
sets apart". the work is to *differentiate*: name what separates each candidate, so exam and
tests can knock out the ones that do not fit.

## .inputs

- `1.intake.yield.md` — the structured history

## .do

- rank candidates by clinical plausibility given the symptoms
- for each, state what **supports** it and what would **argue against / set it apart**
- keep the cardiac track separate — do not conflate the pant question with the lameness
- surface any decisive flag that changes acuity (carry it to `4.triage.yield.md`)

## .emit

into `2.1.differential.enumerate.yield.md`.

## .done when

each candidate carries a separator test, and the list is ranked.
