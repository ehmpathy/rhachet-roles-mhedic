# 2.2.2.gather-experiences.stone

## .what

run the query plan through the bhrowser and collect raw experiences — both directions — with
comments read and quotes saved verbatim. the evidence the itemize step tabulates.

second substone of `2.2.differential.disentangle`.

## .inputs

- `2.2.1.craft-queries.yield.md` — the effect string, exposure set, queries, sources

## .do

1. **start the bhrowser** (`rule.require.bhrowser-citations`; never WebSearch/WebFetch).
2. **forward pass** — per exposure query, per source: navigate → snapshot html → **open threads
   and read the comments** (`rule.require.read-social-comments`). capture the post + the replies.
3. **backtrack pass** — run the effect-first query; for each lame-cat case, note which exposures
   it carried.
4. **favor "X alone" cohorts** — flag cases where one exposure occurred without the others; those
   break the confound.
5. **save verbatim** — for each case: source url, the quote, the subreddit/forum, the date. every
   claim is **signal, not fact**.

## .emit

into `2.2.2.gather-experiences.yield.md` — the raw case list with quotes + urls (this is the
durable `inventory.of=experiences` artifact).

## .caveat

the sample skews to problems (people post when a thing goes wrong). record that here so the
downstream stats carry the bias forward.

## .done when

both passes are run across the multi-source list, comments read, and each case saved with a
verbatim quote + url.
