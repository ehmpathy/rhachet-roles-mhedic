# 2.2.4.compute-correlations.stone

## .what

compute the two-direction correlations per exposure, then **gate on convergence** — proceed if
the sample suffices, else rewind to craft more queries.

fourth substone of `2.2.differential.disentangle`. this is the loop's decision point.

## .inputs

- `2.2.3.itemize-inventory.yield.md` — the tagged table + tallies

## .do

1. **forward** per exposure: `P(effect | X alone)` = (X-alone cases with effect) / (all X-alone
   cases). record the count + n.
2. **backtrack** per exposure: `P(X | effect)` = (effect cases with X) / (all effect cases).
   record the count + n.
3. **caveat every number** — small n, selection bias (skews to problems), association is not
   causation. the forward risk is an **upper bound**, not a base rate.

## .the convergence gate (the rewind)

check: **does each exposure have enough "X alone" cases to attribute independently?**

- threshold (demo): >= 3 "X alone" cases per exposure, and >= 1 has the effect and >= 1 does not
  (else the cell is all-yes or all-no and tells us little).
- **fail** → rewind to `2.2.1.craft-queries` — add queries / sources for the thin exposures, then
  re-run `2.2.2` → `2.2.3` → back here. record the rewind (round count).
- **pass** → proceed to `2.2.5.attribute-rerank`.

```
2.2.1 → 2.2.2 → 2.2.3 → 2.2.4 ──(thin)──▶ back to 2.2.1
                          │
                       (enough)
                          ▼
                       2.2.5
```

## .emit

into `2.2.4.compute-correlations.yield.md` — the two-direction table, the n per cell, the caveats,
and the convergence verdict (pass, or rewind with which exposures were thin).

## .done when

both directions are computed per exposure with n + caveats, and the gate has ruled pass or rewind.
