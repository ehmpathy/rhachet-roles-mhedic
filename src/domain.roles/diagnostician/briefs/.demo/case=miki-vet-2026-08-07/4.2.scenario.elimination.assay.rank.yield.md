## .why the override is not arbitrary — the expected-loss grounding

> the catastrophic override follows from **expected-loss minimization**, not preference. the value of a
> test is the expected harm it averts: `E[loss averted] = P(branch) × loss(branch) − cost(test)`.
> - for a **catastrophic** branch, `loss(branch)` = death / irreversible harm — so large that even a
>   **low** `P(branch)` yields an expected loss that **dwarfs** any test's dollar/time cost. the term
>   `P × death` dominates `cost(test)`, so the test is worth running **regardless of cost or low
>   probability**. this is exactly why a can't-miss branch is carried on severity, not probability
>   (`rule.require.superposition-until-elimination`).
> - for a **mild** branch, `loss(branch)` is small, so cost matters and the ordinary power × (1/cost)
>   order governs.
>
> so the override is the decision-theoretic consequence of asymmetric loss: rank by **expected loss
> averted**, and a catastrophic branch's expected loss dominates every cost term. the cost-rank below is
> the *tie-breaker among comparable-severity tests*, not the master order.

## .the score axes

- **power** = how many live scenarios a test separates (a between-scenario test scores high; a
  within-scenario test scores low)
- **cost** = money + invasiveness + time (owner question ≈ free; in-clinic exam ≈ low; blood/lab ≈ mid;
  radiograph/sedation ≈ high)
- **catastrophic override** = a test that lifts a live **catastrophic** veto (B16, B13) ranks first
  regardless of its cost — the veto it lifts outweighs the price
- **cheap-gap bonus** = a near-free gap-closer (owner question, already-drawn result) ranks high even at
  modest power, because power × (1/cost) explodes as cost → 0

> (front-loads catastrophic-clearers) and **free-first parallelism** (all ≈free tests run in the same

> ⚠️ **the base score alone does NOT set the order** — and this is deliberate, shown here to keep it
> auditable. pure `power÷cost` would rank owner-Qs (5.0) first and bury T4 (0.75) last. two declared
> adjustments override the raw score: (1) **severity** pulls T2 and T4 (catastrophic-clearers) to
> run-tier A regardless of score; (2) **free-first parallelism** groups every ≈free test (G8, owner-Qs,
> G1+G2, T3) into one visit — their *relative* base scores do not matter because they all run together at
> near-zero cost. so a low-score-but-free test (G1+G2 = 1.0) is not "buried" — it runs in the same free
> batch, and it gates a severe branch (B15). the paid tests (T5, T4) are the only ones the score defers,
> and T4 is exempted by the severity override.

> ⚠️ **power is separation RESOLUTION, not raw touch-count.** a raw count of scenarios touched overstates
> a low-resolution test and understates a high-resolution one. the honest measure of *separation*-power is
> how many **distinct groups** a test splits the live set into:
> - **T2** touches 8 but partitions them into **~6 distinct localizations** (vascular / cord / peripheral
>   nerve / joint / bone / soft-tissue) — high resolution; its separation-power is genuinely top.
> - **T1** touches 5 but makes only a **2-way** systemic÷local split — low resolution; a raw count of 5
>   flatters it. its true separation-power is ~2, so its `power÷cost` is nearer 1.0 than 2.5.
> - **G8** answers 4 branches on **distinct organ axes** (renal / hepatic / azotemia / metabolic) — ~4
>   real groups; high resolution holds.
>
> the resolution view does **not** change the run-tiers (T2 stays tier-A on severity; the free batch stays
> tier-B), but it makes the power column honest: separation-power counts *partitions produced*, not
> *scenarios brushed*. the resolution-adjusted scores are noted in the r2 self-review.

## .the override re-rank — catastrophic-clearing tests pulled to the front

> ⚠️ **the numeric rank above is the COST-rank; it must not bury a catastrophic-clearing test.** T4 sits
> at cost-rank 8 (it is expensive), but T4 is also the **tier-2 gate for B13 (spinal, catastrophic)**. a
> reader who follows the raw 1→8 order would run the B13-clearing radiograph *last*, behind cheap
> low-power tests (T5, owner questions) — the exact failure this slug guards against. so the override
> defines an **effective rank** that pulls every catastrophic-clearing test to the front:

| effective rank | test | why front-of-queue | cost-rank it overrides |
|----------------|------|--------------------|------------------------|
| **1 (always)** | T2 exam incl. perfusion | clears B16 (ATE) + B13 (neuro tier-1) | already 1 |
| **2 (when B13 manipulation is contemplated)** | T4 radiograph | tier-2 gate for B13 (spinal) — must precede manipulation-under-sedation | pulled up from **8** |
| then | G8, G1+G2, T1, T3, owner-Qs, T5 | cheap gap-closers + high-power exam adjuncts | 2–7 |
| n/a | (B5 FISS) | no assay — watch item, not a ranked test | — |

**the rule:** a catastrophic-clearing test never sits behind a cheap-but-low-power test. T4's cost-rank
of 8 is honest about its price, but its **effective rank is 2** the moment B13 manipulation is on the
table — the veto it lifts (do not manipulate an unstable spine) is worth the radiograph's cost.

## .the severity gradient of the override — no landmine test at the bottom

> the override is not binary; it is a **gradient** keyed to the severity of the branch a test clears. the
> burial check runs across the whole severity ladder, not only the catastrophic top:

| the test clears a branch of severity… | override strength | placement rule |
|----------------------------------------|-------------------|----------------|
| **catastrophic** (B16, B13) | **hard** | front of queue regardless of cost (T2 eff-1; T4 eff-2 when B13 manipulation) |
| **severe** (B15,B18,B9,B10,B12,B17) | **soft** | never at the very bottom behind a near-useless test; cheap severe-clearers run early |
| moderate / mild | none | ordinary power × (1/cost) |

**the severe-branch burial check:** the only test at the bottom of the cost-rank that clears a severe
branch is **T4** (B12 fracture, severe) — but T4 is **already elevated** by the catastrophic override (it
also gates B13), so B12's severe rule-out rides up with it. every other severe branch is cleared by a
high-ranked test: B15 by G1+G2 (rank 3), B18/B9/B17 by G8 (rank 2), B10 by T2 (rank 1). so **no
severe-clearing test sits at the bottom** either — the gradient holds, not just the catastrophic top.

**the residual bottom (T5 CBC, rank 7):** T5's highest-severity branch is B2/B17 — and B17 is already
covered by G8 (rank 2), while B2 is moderate. so the one genuinely-low-ranked new-draw test clears no
branch above what a cheaper higher-ranked test already covers. the bottom of the queue holds no
un-covered landmine.

## .the catastrophic override — what jumped the queue

- **T2 (perfusion sub-check)** → rank 1 despite cheaper single-purpose tests, because it is the decisive
  rule-out for **B16 (feline ATE)**, a fast-onset catastrophic landmine whose veto fires **pre-test /
  empirically** (act-as-if-ATE on any doubt; the exam confirms in parallel).
- **T4 (radiograph)** → lifted from "last, high-cost" to a **conditional priority** wherever B13
  (spinal) manipulation is contemplated: it is the second tier of the two-tier B13 lift and must precede
  any manipulation-under-sedation.
- **B5 (FISS)** has **no assay** — it is not in the ranked list; it is a longitudinal **watch item**
  (3-2-1 surveillance) and a persistent phase-9 veto, not a test to run today.
