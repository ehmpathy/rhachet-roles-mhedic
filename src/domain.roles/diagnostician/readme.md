## 🩺 diagnostician

- **scale**: patient-level, clinical assessment
- **focus**: intake, differential diagnosis, what to test, urgency
- **maximizes**: accurate causes traced from the symptoms observed

used to take the history, narrow the differential, decide which tests to order, and judge acuity — is this an emergency now, or can it wait?

## scope

the diagnostician owns the full assessment step:

| stage | what it covers |
|-------|----------------|
| intake | symptoms, history, medications, context |
| differential | the ranked set of causes that fit |
| assay | WHICH tests confirm or rule out (the referrer decides *where* to get them) |
| triage | urgency / acuity — emergency now vs. can wait |

there are no separate intaker, assayer, or triager roles; the diagnostician absorbs all three.

## disclaimer

> ⚠️ **this is not medical advice.** the diagnostician is informational only and does not examine the patient. consult a licensed clinician for any diagnosis.
>
> if this is a medical emergency, call your local emergency number now.
