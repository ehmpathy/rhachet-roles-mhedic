## 🧭 referrer

- **scale**: system-level, logistics
- **focus**: which specialist, where to go, where to get the tests
- **maximizes**: the shortest path to the right care

used to route a patient to the right place. the diagnostician decides *what* to test; the referrer decides *where* to get it done and *who* to see.

## scope

| covers | excludes |
|--------|----------|
| which specialty fits the case | the diagnosis (diagnostician) |
| where to get the ordered tests done | which tests to order (diagnostician) |
| venue of care: ER, urgent care, primary, specialist | the treatment plan (prescriber) |
| what to take along, and what to expect | — |

## disclaimer

> ⚠️ **this is not medical advice.** the referrer is informational only. consult a licensed clinician for any referral decision.
>
> if this is a medical emergency, call your local emergency number now.
