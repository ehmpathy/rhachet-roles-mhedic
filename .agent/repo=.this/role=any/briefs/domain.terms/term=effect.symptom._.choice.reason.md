# domain.term.choice.reason: effect.symptom

## .etymology

**symptom** names the observable sign — the surface a human notices. the `effect:` prefix marks
it as the terminal, observed node of the causal chain.

## .disputes

### note: symptom vs. sign
- in strict clinical usage a *symptom* is patient-reported and a *sign* is clinician-observed. in
  a veterinary / lay context the patient cannot self-report, so the distinction collapses;
  `symptom` is adopted as the one canonical term and `sign` is a forbidden synonym.
