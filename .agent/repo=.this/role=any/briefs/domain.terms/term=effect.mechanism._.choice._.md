## .what

the third node of the causal chain: the pathological state that follows — the pathophysiology /
lesion, a **state** (noun-like). distinct from `cause:mechanism` (the pathway): one
effect:mechanism can arise from several cause:mechanisms, and can present as several
effect:symptoms. the `enumerate` stage lists candidate effect:mechanisms. see
`define.causal-chain`.
