# domain.term.choice.reason: superposition

## .etymology

`superposition` (physics) = a system held in many states at once, each with an amplitude, until a
measurement collapses it to one. the diagnostic parallel is exact: many scenarios coexist, each
weighted, until an assay eliminates some. the word carries the two properties the method depends on —
**many-at-once** and **collapse-by-measurement** — that no plainer word carries together.

chosen over:
- **`differential`** — the medical set of candidate diagnoses, but it names only the *states*, with
  no weights and no consequence packages. a superposition is states + weights + packages. the
  differential is what enumeration (phase 2) produces; the superposition is what the later phases
  build from it.
- **`distribution`** — names the *weights* (a probability distribution) but not the states or their
  packages, and it implies a settled measure rather than a live set that a test still collapses.
- **`shortlist` / `lineup`** — the pre-weight set (enumeration output), not the weighted, packaged,
  collapsible object.

## .evidence

- discovery: the frame needed a word for "the whole ranked live set, each state a full package, which
  a test collapses." physics already names exactly that structure.
- composed three times in the route, at three grains: `scenario.superposition` (build it),
  `diagnosis.superposition` (present it), `treatment.superposition` (plan its envelope).
