# domain.term.choice.reason: alert

## .etymology

"alert" is used here as the *composite unit* a hazard is fitted with — the {monitor, alarm} pair —
because the rule's ask is "establish the alerts (monitors + alarms)". it is the noun for the whole
watch apparatus on one hazard, one level above the two parts it contains.

## .disputes

### dispute: alarm vs alert — raised 2026-08-10 — status: RESOLVED (distinct, not synonyms)
- raised.by  = owner
- claim      = alert and alarm are the same
- counter    = they name different layers. alarm = the threshold that fires; alert = the
               established pair (monitor + alarm) per hazard. to collapse them loses the monitor
               half. a deliberate part/whole split, not a synonym pair.
- resolution = keep both; alert = the pair, alarm = the fire-condition. record `notification` and
               `signal` as forbidden synonyms of alert.

## .evidence

- `rule.require.hazard-alerts` (alert = monitor + alarm, established per hazard)
