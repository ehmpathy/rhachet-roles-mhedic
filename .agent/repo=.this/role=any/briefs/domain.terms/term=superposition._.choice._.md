# domain.term: superposition

term.chosen   = superposition
term.kind     = noun
term.synonyms.forbidden:
- differential (the bare set, no weights/packages)
- distribution (the weights alone, no states/packages)
- shortlist
- lineup (the pre-weight set — that is enumeration output)

## .what

a probability-ranked set of **live scenarios**, each held at once with its weight **and** its
consequence package — the object a diagnosis is, before (and after) a test collapses it. borrowed
from quantum mechanics: many states coexist, weighted, until a measurement (here, an assay)
eliminates some. distinct from a bare `differential` (states, no weights) and a bare `distribution`
(weights, no states/packages).
