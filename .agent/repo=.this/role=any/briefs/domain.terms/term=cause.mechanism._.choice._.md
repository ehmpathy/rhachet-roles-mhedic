## .what

the second node of the causal chain: *how* an exposure does harm — the mechanism-of-action, a
**process / pathway** (verb-like). distinct from `effect:mechanism` (the state it yields): one
cause:mechanism can produce several effect:mechanisms. see `define.causal-chain`.
