# domain.term.choice.reason: obscure

## .etymology

**obscure** — latin *obscurus*, "dark, covered over," from *ob-* "over" + a root for "cover."
it names **what is covered from light**, which is exactly the middle rung of the horticultural
gradient `term=fullsun._.choice.reason.md` records: *partial shade*.

⇒ the decisive property the word carries and its rejects do not: **shade is a CONDITION, not a
container.** a plant in partial shade can be moved into sun; a plant in a locked box cannot. so the
word already implies the graduation trigger, before any rule states it.

chosen over the rejected set for one reason each:

| rejected | why |
|---|---|
| `secret` | 🔴 asserts **permanence**, which is the exact inverse of this posture. *"an obscure artifact graduates"* parses; *"a secret graduates"* does not |
| `private` | names the **audience**. orthogonal — an artifact can be private and fullsun, or public and obscure |
| `confidential` | borrows a **legal** posture that belongs one rung up, at 🔒 protect. to use it here would blur the one boundary that matters: reversible vs irreversible |
| `internal` | names a **location**. an obscure artifact may sit in a public repo, held only by its trigger |
| `redacted` | names a **transform already applied**. obscure is the verdict that *calls for* one — a state before the act, not after |
| `withheld` | names the **act of a hold** and gives no account of why value is held. the posture axis is value, never action |

## .disputes

### dispute: is `secret` the plainer word? — raised 2026-09-08 — status: RESOLVED (no — it inverts the claim)

- raised.by = the observation that *"secret"* is the word a layperson reaches for, and this repo
  prefers plain domain words
- claim = `obscure` is an unusual adjective-as-posture; `secret` reads instantly
- counter = 🔴 **it reads instantly and it reads WRONG.** `secret` asserts a permanent state.
  `rule.require.publishability-triage` declares the opposite in as many words: *"obscurity is a
  delay, not a right — the trigger forces the eventual sunning so the fullsun upside is not lost to
  inertia."* a reader who takes *"secret"* at face value never writes a trigger, and the artifact
  is held forever by default
- resolution = keep `obscure`; `secret` forbidden. ⚠️ **the plainer word would have encoded the
  defect the rule exists to prevent** — a case where legibility and correctness pull apart, and
  correctness wins

### dispute: is `obscure` distinct from `protect`? — raised 2026-09-08 — status: RESOLVED (distinct — the axis is reversibility)

- raised.by = both postures mean *"do not publish"*, so a triager may treat them as one bucket with
  two labels
- claim = one concept, two intensities ⇒ a needless split
- counter = 🔴 **the disposition differs, not merely the degree.** an obscure artifact **must**
  graduate on a written trigger; a protect artifact has no trigger and correctly never moves. and the
  leak costs part cleanly: a lead you can rebuild vs a right that does not return
- resolution = distinct. ⚠️ **the tell for a triager: can you name a real, checkable event after
  which publication is fine?** yes → 🕶️ obscure. no, and never → 🔒 protect

## .evidence

### three of the four leak tests land here

`rule.require.publishability-triage` runs four tests. optionality, insight, and voice all set
🕶️ obscure; only fingerprint splits (applied narration → obscure, the mechanic itself → protect).

⇒ **obscure is the modal verdict**, which makes its two failure modes the common ones: a tag with no
trigger (an unbounded hold), and a set-level leak assigned per-file (the voice test).

### the set-level case, which is the one a per-file audit cannot reach

every brief individually: no client name, no settled recommendation, no standalone aha ⇒ each passes
as ☀️ fullsun. **the set**: one repeat protagonist, both sides of every line described, the same
actor always on the safe side, briefs cross-referenced into one design ⇒ **the set is 🕶️ obscure.**

🔴 **so the correct tag for a corpus can differ from the correct tag for every one of its members.**
that is the property `publishable` cannot express and this posture can.

## .invariants

- an obscure tag with **no graduation trigger** is incomplete — an unbounded hold, never a posture
- the axis is **value**, never harm. an artifact held because exposure hurts a person is 🔒 protect
- 🔴 obscure is assignable to a **set** whose every member is fullsun
