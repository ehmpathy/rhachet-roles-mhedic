## .the gap, precisely

**an ordered artifact asserts `n-1` claims that no word in it names.** a ranked differential, a
priority list of tests, a triage tier — each pair of neighbouring places is an assertion that a
source separates them, and **no extant term points at that assertion**, so:

- no rule can attach to it
- no reviewer can be asked *"is it sourced?"*
- and it survives every numeric audit, because **it carries no digit**

checkable evidence, this route — six instances in ONE review, **not one with a numeral**:

| instance | the disguise | the verdict |
|---|---|---|
| a twelve-place ask order `0, 1, 1b … 11` | a **rank** | 🔴 120 pairwise claims; the corpus supplied a handful |
| the seven-row floor tier `1`–`7` | a **rank** | 🔴🔴 **contradicted by the artifact itself** — row 3's own cell read *"the row that kills fastest"*, which on a severity axis argues it belongs first |
| handoff 4 · handoff 20 | a **superlative** | 🔴 the two sentences I was using as the **RULER** |
| handoff 1 / 1b — *"likeliest"* | a **superlative** | 🔴 an empty comparison class — one hypothesis ranked against zero |
| *"all five pass it. **no other ask does**"* | a **universal** | 🔴🔴🔴 **inside the repair itself**, and false — G6 fails it |
| ✅ the probability **brackets** | — | ✅ **the CONTROL. passed.** each bound one-sided and separately sourced ⇒ no adjacency asserted |

🔴 **the control is what makes the audit credible rather than fault-manufacturing** — the same
instrument that failed two ordered tables passed the brackets, so it discriminates.

## .the shape of the fix — for bhrain, not here

### 1. a term cluster — `term=order.adjacency._.choice._.md` + `.reason.md`

- **chosen**: `adjacency`
- **kind**: noun · **boundary**: `order`
- **`.what`**: *the claim an ordered artifact makes about ONE neighbouring pair — that some source
  places A before B. an order over `n` items holds `n-1` adjacencies and asserts `n(n-1)/2`
  pairwise judgments.*
- **forbidden synonyms**, each with its reason:

  | forbidden | why |
  |---|---|
  | 🔴 **`separation`** | a **measure**, not an object — so an artifact still needs a second noun for the pair, which is synonym sprawl by construction. ⚠️ **this is verbatim the argument that rejected `span` for `citation.excerpt` one round earlier, and it did not transfer** |
  | `gap` | 🔴🔴 **already overloaded in this domain** — `1.3.intake.gaps` owns `gap` for an unanswered ask (`G1`–`G39`). one word, two concepts = `rule.forbid.domain-term-ambiguity` |
  | `ordering`, `precedence` | name the whole order, never the single pair — so *"cite the precedence"* cannot ask for `n-1` citations |
  | `delta`, `interval` | numeric; they imply a measurable distance the corpus does not supply. the whole point is that the claim is **ordinal** |

⚠️ **`order` must be declared first** — `rule.require.boundary-qualified-terms` grades *"a boundary
naming no declared term"* a blocker, and **no repo declares `order` today.** that is the first
piece of work, not an afterthought.

### 2. 🔴 the GENERAL form of the rule — it does not exist

this repo holds `rule.require.cite-the-adjacency-not-the-item.[rule].md`, which is the **medical
specialization**: its `.why` turns on *"the item at the top is the act that gets done first"*, and
its enforcement targets differentials and test-priority lists.

⇒ per `rule.require.specialize-a-rule-its-readers-look-past`, **a specialization cites a parent**,
and this one has none to cite. the parent is owed to bhrain and should carry:

- the test — *for each pair, what source ranks A above B?*
- **the three disguises** — a count (reads as clerical) · a **rank** (reads as ORGANIZATION, and
  the reader **executes** it) · a **superlative** (**carries no digit**, so no numeric sweep reaches it)
- 🔴 **the repair: DECLARE, do not renumber.** a re-sort is wrong twice — it invents a *different*
  unsourced order, **and** it breaks every reference that addresses rows by number. keep the
  numerals as stable labels, withdraw the rank claim in words, group into coarse tiers with a
  **stated, mechanical membership test**
- 🔴 **the corollary** — when a review coins a test, the artifact that provoked it is the one case
  you already know the answer for. run it on **every** artifact in scope, **including the sentences
  you reach for as the ruler.** ⚠️ *a rank hides best inside the sentence that condemns another rank*

### 3. the cheap variant, if a full rule is judged too heavy

make the review guide's `ordinal (rank), not magnitude` line **name its own object** — *"can you
cite each adjacency?"* — so the reviewer is asked for `n-1` citations rather than a vibe. the whole
r2 miss traces to a guide that named the fault and never the thing.

## .why it is not done in this round

- **SAFE?** ✅ yes — a term cluster and a parent rule are both additive.
- **CLEAN?** 🔴 **no, and for jurisdiction plus an absent prerequisite.**
  - **jurisdiction** — ordering discipline is bhrain's. this repo's declared practices are
    citations, inventories, the causal-chain frame, diagnosis-superposition, hazard alerts. per
    `rule.always.scope-onetime-lessons-to-the-behavior`, *"a lesson whose home is another repo is
    re-seeded there, never adopted here."*
  - **prerequisite** — `order` is declared nowhere, so a correct cluster cannot be written today
    without also minting its boundary in a namespace this repo does not own.
- ✅ **the in-scope half WAS done now**: the drift is conformed to `adjacency` across the r3
  self-review, and the medical specialization is complete and enforceable as it stands.
