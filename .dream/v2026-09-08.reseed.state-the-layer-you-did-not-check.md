# 🌙 dream: a completion report must state the layer it did NOT check

**kind** = reseed (belongs to `bhrain/role=learner`, or `bhrain/role=reviewer`)
**owner** = bhrain
**caught** = 2026-09-08

## .the cue that fired

five consecutive rounds of a terms-and-citations audit. **each round found a defect in the layer the
previous round's summary had stopped at:**

| round | the layer it audited | the layer it did not name |
|---|---|---|
| 4 | filenames | rule names |
| 5 | rule names | see-also lines |
| 6 | see-also lines | foreign markers |
| 7 | foreign markers | `.refs` paths |
| 8 | `.refs` paths | whether the cited urls still reach their targets |

⇒ every one of those summaries read as complete. **not one of them was false** — each was true of
the layer it searched, and silent about the layer beneath.

## .the gap, precisely

a completion report states **what it checked**. it does not state **what it did not check**, so a
reader cannot tell a thorough audit from a shallow one — both render as *"✅ clean."*

🔴 **the asymmetry is the whole defect.** the checked set is visible in the report; the unchecked set
is visible nowhere, and it is the set where the next defect lives.

⚠️ and it compounds: the next round inherits the summary, treats *"clean"* as settled, and starts
one layer further in — so the unchecked layer gets **less** scrutiny each round, not more.

## .the shape of the fix

a rule, roughly `rule.always.state-the-layer-you-did-not-check`:

> **a completion report owes a LEDGER: the layers checked, and the layers named-but-unchecked.**
> an unchecked layer stated is a task. an unchecked layer unstated is a false clean.

the ledger's minimum row set:

| field | why |
|---|---|
| **what was checked** | the extant half of every report |
| **what was NOT checked, by name** | the half that makes the report falsifiable |
| **the scope** — which tree, which pattern | *"0 matches"* is true only of what was searched |
| **the date** | a verification's truth value changes while the file sits untouched |

⇒ the test: **"a reader who trusts this report — what would they wrongly believe is settled?"**
name that, and the ledger is complete.

## .the two peers already paved, which this generalizes

- `rule.forbid.pii` (mhedic) now carries the **scrub-specific** instance: scrub the source tree not a
  built view · enumerate spawned names · a scrub result carries a scope and a date
- `term=citation._.choice._.md` (mhedic) carries the **citation-specific** instance: a citation's
  truth value changes with time, so a citation verified once is not verified

🔴 **two instances in one repo, in one week, is the signal the general rule is owed** — and it is owed
in bhrain, where the audit and review disciplines live, not in the medical repo where it was found.

## .why it is not done in this round

- **safe?** yes — a new brief harms no extant artifact
- **clean?** 🔴 **no.** the durable home is `bhrain/role=learner`, not this repo. per
  `rule.always.scope-onetime-lessons-to-the-behavior`, a lesson whose home is another repo is
  **re-seeded there, never adopted here** — a tree adopts only what is scoped to itself

⇒ the two repo-scoped instances landed here this round. the genus is queued for bhrain.
