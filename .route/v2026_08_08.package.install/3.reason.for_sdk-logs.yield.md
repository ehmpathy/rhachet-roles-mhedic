# reason: sdk-logs@0.9.2

## package
- name: sdk-logs
- version: 0.9.2
- type: prep

## reason
the declastruct-github 1.8.0 bump tightened the LogMethods contract (a required `_` property).
the canonical provision wiring in ehmpathy/declastruct-github supplies it via genLogMethods()
from sdk-logs rather than a hand-rolled log object, so the shape cannot drift again on the
next bump. sdk-logs was already present transitively (via rhachet); this declares it directly
so provision/github.repo/resources.ts may import it.
